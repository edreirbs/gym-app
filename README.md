# gimnasio-apps

Rutinas de gimnasio de Edrei y de Zuly como páginas web de un solo archivo, con figuras 3D que muestran la técnica de cada ejercicio.

- `edrei/rutina.html`: rutina de Edrei (v13.1).
- `zuly/zuly.html`: rutina de Zuly (fase 2), se arma con `python3 zuly/build.py`.

Para trabajar con Claude Code: lee `CLAUDE.md` y `HANDOFF.md`.
